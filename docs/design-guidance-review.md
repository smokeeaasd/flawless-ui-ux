# Design guidance balance

## Scope and evidence

This review addresses repeated user feedback that refinement can make interfaces too plain while promotional repetition persists. Source inspection identified steering risks in the instructions; it does not establish that any single sentence caused a rendered regression. Host outcomes for the revised guidance remain pending.

The installed package remains one adaptive skill. This change introduces no additional runtime guide, model runner, prescribed palette, font list, mandatory visual concept, or fixed pass sequence.

## Steering risks and corrections

| Risk identified | Correction | Boundary retained |
|---|---|---|
| Clarity and working behavior described as sufficient goals | Treat correctness and access as baseline, with composition, character, and finish evaluated against the requested result | No novelty requirement or automatic aesthetic score |
| Expression appears conditional on a user naming a more expressive direction | Infer suitable visual ambition from audience, material, and surface | No invented product claims, compulsory metaphor, or permission to replace an established identity |
| "Enterprise" or "polished" interpreted as a quieter palette and less detail | Diagnose maturity through the task and current identity before choosing a visual adjustment | Accessibility and real operational needs still govern execution |
| A functional purpose required for each visual treatment in isolation | Assess hierarchy, atmosphere, identity, and material character together | Fix misleading controls, illegibility, and competing emphasis where observed |
| Copy cleanup treated as broad visual simplification | Separate informational repetition from composition, type, color, and imagery | Follow the actual intervention boundary |
| Guidance against slogans remains abstract despite observed recurrence | Add an editorial pass with original before/after reasoning and a second reading of the full sequence | No slogan quota, punctuation ban, forced literal voice, or fabricated replacement facts |
| Protected wording conflicts with expectations to remove slogans | In visual-only refinement, retain wording and report material copy concerns separately | Copy changes require authorization through the request |
| A small set of study images becomes a visual ceiling | Explain how structural principles support different visual registers | The studies remain examples rather than templates or evidence of working behavior |
| Singular accent wording suggests a universal palette limit | Define color roles without an accent-count or saturation rule | Semantic distinction, contrast, and explicit brand constraints remain |

The audit also checked typography, hierarchy, spacing, imagery, and motion guidance. Existing constraints on readability, honest claims, real interactions, reduced motion, and scope were retained. A font size, familiar layout, or visual effect remains a reason to inspect its use, not a universal defect.

## Validation and remaining work

Package checks establish internal references, metadata, encoding, and installation integrity. They do not establish better design judgment.

The optional [refinement follow-up](../evals/cases/09-refinement-continuity.md) starts from one preserved creation result and uses independent copies for visual-only and copy-only interventions. Keep the model and conditions fixed between revisions. Inspect visual continuity, specific craft improvements, copy contribution, product truth, scope, and verification evidence. Cases 03 and 05 remain useful controls for narrow changes and explicit brand preservation.

No host runs of this follow-up are claimed here. Existing informal reports and research remain distinct from a completed controlled comparison.
