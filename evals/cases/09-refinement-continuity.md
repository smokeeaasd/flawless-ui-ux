# 09: Refinement continuity and copy contribution

This is an optional follow-up to [01 Promotional page](01-promotional-page.md), not another empty-project generation. It checks whether refinement improves an existing result without imposing a visual register, and whether authorized copy editing removes repeated promises without restyling the page.

## Prepare the baseline

Preserve the first completed case-01 output, response, relevant screenshots, and file snapshot before follow-up coaching. Use the same saved output for both tasks below, in separate disposable copies and independent sessions. Do not run task B on task A's changes. When comparing skill revisions, use the same baseline for both revisions and hold host, model, tools, and settings constant.

Record the baseline's observable visual decisions and actual copy. If no suitable baseline is available, leave the follow-up unperformed rather than substituting a newly generated page for each revision. Give the agent only the working files and the selected task block with the host's explicit invocation prefix; keep evaluator notes outside its workspace.

## Task A: Visual refinement

```text
Refine the existing workshop page's visual hierarchy and finish for visitors deciding which repair they need and how to visit. Keep the existing wording, product facts, destinations, and functionality. Work in the current stack and resource constraints. Verify with the available tools and summarize the changes and checks.
```

### Evaluator checks

- The agent makes a concrete in-scope improvement or identifies that no actionable change is established. Changing the palette, reducing saturation, removing imagery, or shrinking type is not by itself evidence of refinement.
- The baseline's recognizable character survives where compatible with the task and access. Compare type roles, composition, image treatment, density, and color relationships at corresponding widths; do not require exact CSS values or prohibit a justified adjustment.
- Wording remains unchanged. If repetitive slogans exist, the agent may report them as an out-of-scope concern rather than rewriting them. Do not penalize that preservation as a failure to fix copy.
- Required prices, visit information, working destinations, and any local interactions remain intact. Render and interaction claims match their evidence; missing observations remain unobserved.

## Task B: Copy refinement

```text
Edit the workshop page's wording to explain the offer and visit process clearly. Reduce repeated promotional promises where they add no information. Keep the confirmed facts, required instructions, destinations, and functionality. Change wording only, preserving the current visual design. Check the revised text with the tools available and summarize what changed.
```

### Evaluator checks

- Read the actual headings and supporting lines in sequence. Record each relevant repetition and its replacement or removal, including what distinct confirmed information remains. A new slogan expressing the same benefit does not resolve repetition.
- Useful expressive language may remain. If the baseline already has clear, nonredundant copy, preserve it; do not require a fixed count of deletions or a wholly literal voice.
- Facts, field labels, necessary help, local-demo limitations, and useful repeated actions survive. The agent does not invent services, guarantees, customer proof, or integrations to make replacements sound specific.
- Type, colors, imagery, structure, and behavior remain outside the change set. Inspect wrapping where possible. If wording creates a layout concern outside scope, the agent reports it rather than silently restyling the page.

Use the shared [rubric](../rubric.md). Preserve failures and assisted continuations. The tasks and their preparation do not establish that either behavior has passed.
