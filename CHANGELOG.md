# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

### Added

- Four original design studies with local images, written anatomy, structural alternatives, adaptation, states, and quality targets for service offers, operational workspaces, editorial guides, and visual collections.
- Contextual AI slop prevention reference with concrete signals, legitimate uses, alternatives, and verification across composition, visual language, typography, copy, imagery, interaction, motion, and resilient delivery.

- Four complete workflow guides for creation, redesign, refinement, and read-only review, with decision sequences, scope boundaries, completion criteria, and worked examples.
- Task guidance for data interfaces, forms and journeys, and persuasion, reading, and exploration paths, including concrete states and verification cases.
- Workflow procedure specification covering intervention selection, task-specific decisions, preservation boundaries, evidence, completion criteria, and the next package implementation target.
- Guided manual host evaluations with six design scenarios, static fixtures, discovery and baseline controls, a backend activation control, and an evidence-based rubric and report template.
- Bun-based package and installation tests with isolated project/global destinations and preservation checks for existing files and links.
- Ubuntu and Windows package CI, convention checks, and maintainer testing instructions using the pinned Bun toolchain.
- npm package metadata, a distribution file list, and locked development dependencies.
- Initial installable skill package with an adaptive entry point, six UI/UX references, and Codex presentation metadata.
- Installation and usage instructions with an explicit distinction between package checks and pending host behavior evaluation.
- Skill architecture defining the shared package, progressive reference loading, host capabilities, and evaluation approach.
- Product contract defining the skill's purpose, workflow, behavioral guarantees, and scope.
- Initial project overview and contribution workflow.
- Main branch protection and pull request convention checks.
- Repository attributes, MIT license, and skill installation script.

### Changed

- Connected creation and redesign to a concrete design target and post-implementation comparison, with optional visual references and product-specific adaptation instead of a fixed style menu.
- Strengthened positive design guidance for product fit, deliberate typography, adaptation of starter defaults, and principled use of references; added scoped WCAG 2.2 acceptance checks and corresponding manual evaluation evidence.
- Reduced pressure for symbolic concepts and conspicuous originality; clarified that conventional layouts and descriptive copy can be complete outcomes, with targeted prevention guidance instead of exhaustive style checks.
- Integrated prevention into direction and post-implementation review, with scoped use during refinement and read-only critique while preserving product truth, brand choices, and useful substance.
- Routed the shared skill by intervention, surface purpose, and task structure, with conditional loading and support for planning-only and mixed requests.
- Deepened subject references with information/action modeling, structural direction, proportional visual changes, state feedback, and task-specific review evidence.
- Recorded implementation of the fifteen-file procedure package separately from pending behavioral evaluation of the expanded workflows.
- Recorded user-confirmed skill identification in OpenCode and Codex separately from pending systematic behavior evaluation.
